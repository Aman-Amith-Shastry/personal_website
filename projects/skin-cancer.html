Skin Cancer Classification

Independent · 2023 · early work

TensorFlowKerasResNet-50VGG-16scikit-learnOpenCV

Overview

One of my first machine learning projects, from before college: benign versus malignant classification of dermoscopic lesion images.

I tried several approaches on the same problem — two pretrained networks, an ensemble of the two, and a decision tree — and compared what each one scored. I was still learning how these methods work at the time, and the project reflects that: it is a survey of techniques I wanted to get my hands on rather than a considered argument for any one of them. I have left it here because it is where I started, not because it is representative of how I work now.

How it works

Transfer learning
ResNet-50 and VGG-16 with their ImageNet backbones frozen, each given a new classification head, so only the head was trained on the lesion images.
Ensemble
The two networks combined in a weighted average of their outputs — the two architectures disagree on different images, so averaging them recovers a little of what either one alone misses.
Decision tree
A third approach rather than a reference point: a tree fitted directly on raw grayscale pixel values, with no features engineered for it. It has no notion of shape, texture, or border irregularity, so whatever it gets right it gets from brightness patterns alone.
Evaluation
All four scored on the same held-out split, so nothing is compared across different data.

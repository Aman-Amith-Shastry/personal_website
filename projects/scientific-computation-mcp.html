Scientific Computation MCP Server

Overview

I kept watching language models talk their way through a matrix decomposition token by token and get it subtly wrong, so I wrote a server that hands the work to NumPy and SymPy instead.

It exposes linear algebra, vector calculus, and plotting over the Model Context Protocol, so any compatible client can call it as a tool. The failure it fixes is specific: a model asked for the eigenvalues of a 4×4 matrix will produce something plausibly shaped and quietly off, and nothing downstream flags it. Routing the computation to a numerical library means the answer is either right or an error, never confidently wrong.

It was published on Smithery and indexed on Glama and LobeHub, and reached a peak of 25,000 tool calls a month. That deployment is no longer active, so there is nothing hosted to connect to — the source is still public and still runs locally or from the Docker image.

How it works

Server
FastMCP from the Python MCP SDK, mounted inside a Starlette application with CORS so it can be reached over HTTP as well as through a local stdio client. Shipped as a Docker image with a Smithery manifest.
Tensor store
The design decision the rest hangs on: tensors are created once, given a name, and kept server-side. Every subsequent tool takes names rather than arrays, so a model can build a matrix, decompose it, change its basis, and take a determinant without ever serializing the numbers back through its own context — which is both where the token cost lives and where transcription errors creep in.
Linear algebra
NumPy underneath. Addition, subtraction, multiplication, and scaling with compatibility checks; inverse, transpose, determinant, and rank; eigenvalues and eigenvectors; QR and SVD factorization; orthonormal basis extraction; and change of basis.
Vector calculus
SymPy on a 3-D coordinate system, so the input is an expression rather than a grid of numbers — gradient("x^2 + 2xyz + zy^3") parses and differentiates symbolically. Also projection, dot and cross products, curl, divergence, the Laplacian for both scalar functions and vector fields, and directional derivatives with optional normalization of the direction.
Visualization
matplotlib rendered through the Agg backend straight into a buffer and returned as an MCP image — 3-D vector fields over configurable bounds, and 2-D or 3-D function plots. No files, no display server.
